# 🗺️ KML kaardiprojekt

Veebiprojekt, kus sama **KML-faili** kasutatakse kahe erineva JavaScripti kaarditeegiga: **LeafletJS** ja **OpenLayers**.

Projektis kuvatakse kooli asukoht, kodukoht, kooli ja kodu vaheline teekond ning kodukohta tähistav kujund.

## Projekti eesmärk

Projekti eesmärk on õppida:

* KML-faili kasutamist veebikaardil;
* LeafletJS-i ja OpenLayersi kasutamist;
* interaktiivsete kaartide loomist;
* JavaScripti funktsioonide lisamist;
* erinevate kaarditeekide võrdlemist.

## Projekti struktuur

```text
projekt/
├── index.html
├── leaflet.html
├── openlayers.html
├── comparison.html
├── style.css
├── script.js
└── TECHNO-KODU.kml
```

* `index.html` – avaleht
* `leaflet.html` – LeafletJS-i kaart
* `openlayers.html` – OpenLayersi kaart
* `comparison.html` – kaarditeekide võrdlus
* `style.css` – kujundus
* `script.js` – JavaScripti funktsioonid
* `TECHNO-KODU.kml` – geograafilised andmed
